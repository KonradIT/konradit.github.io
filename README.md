## The hand-coded website

This is the source code for my personal site, which doesn't need any fancy graphics, >20MB bloat video animations, javascript spyware, cookies, ads, chatbots, whatever hell we concocted together in the past decade or two.

It does what it's supposed to do, and nothing more. The page loads fast. It looks good on a 50" screen and on a phone. The drone photo is dope.

Instead of abdicating my intelligence and having an LLM write a fancy website with hue gradients, [the tell-tale of slop](https://prg.sh/ramblings/Why-Your-AI-Keeps-Building-the-Same-Purple-Gradient-Website), the code herein is still written by me, with no LLM help, with nothing but vim and `python3 -m http.server` to preview the html output.

Writing code by hand will be counter-culture in the near future, this website is my small refuge to still hammer down and reason about how to display content on a screen, this website is **original**, your vibe coded B2B SaaS slop looks like every other website out there. you will inadvertly introduce a vuln in your express server given that npm has more holes than a russian refinery, meanwhile try and hack this thing.
